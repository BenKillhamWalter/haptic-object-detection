# Prosthetic Hand — Object Recognition System
## Complete Workflow Guide

---

## Folder Structure

```
prosthetic_hand/
├── 1_data_collection/
│   └── data_collection.ino     ← Flash this to collect training data
├── 2_training/
│   ├── logger.py               ← Run on laptop during data collection
│   ├── train_and_export.py     ← Run to train RF and export model
│   └── grasp_data/             ← CSV files saved here by logger.py
└── 3_inference/
    ├── inference.ino           ← Flash this for final deployment
    └── model.h                 ← Generated by train_and_export.py (copy here)
```

## Hardware Summary

| Component | Detail |
|---|---|
| Controller | OpenRB-150 (SAMD21, 32KB SRAM, 256KB Flash) |
| Motor | Dynamixel XM430-W350-R (ID 1), open=33°, close=90° |
| Multiplexer | TCA9548A at I2C address 0x70 |
| Strip 1 (TCA ch0) | 4 sensors: Index ID1+ID2, Thumb ID3+ID4 |
| Strip 2 (TCA ch1) | 2 sensors: Middle ID1+ID2 |
| Library | arduino-MLX90393 by Theodore Yapo (provided) |

### Sensor addressing (on each strip)
| Sensor | A1 pin | A0 pin | begin() call |
|---|---|---|---|
| ID1 | LOW  | LOW  | begin(0, 0) |
| ID2 | LOW  | HIGH | begin(0, 1) |
| ID3 | HIGH | LOW  | begin(1, 0) |
| ID4 | HIGH | HIGH | begin(1, 1) |

## Step 1 — Install libraries

In Arduino IDE:
- Install **Dynamixel2Arduino** via Library Manager
- Manually install **arduino-MLX90393**: Sketch → Include Library → Add .ZIP Library → select the provided zip

In Python (on your laptop):
```bash
pip install pyserial pandas scikit-learn matplotlib micromlgen
```

---

## Step 2 — Data collection

### 2a. Flash and run
1. Flash `1_data_collection/data_collection.ino` to the OpenRB-150
2. On your laptop, run:
   ```bash
   cd 2_training
   python logger.py
   ```
3. Open Arduino Serial Monitor at 115200 baud to see status messages

### 2b. Collect grasps
For each grasp:
1. Place object in the gripper workspace
2. Type one of these labels in the Serial Monitor + press Enter:
   - `cylinder_stiff`
   - `cylinder_soft`
   - `cube_stiff`
   - `cube_soft`
3. Step back — the hand grasps automatically after 2 seconds
4. The hand releases and returns to open position
5. Repeat

**Target: minimum 20 grasps per object (80 total)**
Vary the object's position and orientation between grasps.

### 2c. Tuning tips (if contact not detected)
In `data_collection.ino`, adjust these constants at the top:

| Parameter | Default | If contact missed | If false triggers |
|---|---|---|---|
| `CONTACT_THRESHOLD` | 40.0 | Decrease | Increase |
| `GRASP_SPEED_RPM` | 10.0 | Increase slightly | Decrease |
| `ENCODER_STILL_DEG` | 0.5 | Increase | Decrease |

Do a few test grasps with no object, check CSV noise values on each axis,
then set `CONTACT_THRESHOLD` to 3-5× that noise floor.

## Step 3 — Train the model

```bash
cd 2_training
python train_and_export.py
```

This will:
1. Load all CSV files from `grasp_data/`
2. Extract 56 features per grasp (at t1 and t2)
3. Train a Random Forest (20 trees, max depth 8 by default)
4. Print cross-validation accuracy and feature importances
5. Save `confusion_matrix.png` to `grasp_data/`
6. Write `model.h` and `feature_names.txt` to `3_inference/`

### Tuning the RF
```bash
python train_and_export.py --trees 15 --depth 6    # smaller/faster (better for limited SRAM)
python train_and_export.py --trees 25 --depth 10   # larger/more accurate
```

**OpenRB-150 limits:** stay at ≤25 trees, ≤10 depth to fit in 256KB Flash.

---

## Step 4 — Deploy inference

1. Ensure `model.h` is in the `3_inference/` folder (generated in Step 3)
2. Open `3_inference/inference.ino` in Arduino IDE
3. Flash to the OpenRB-150
4. Open Serial Monitor at 115200 baud
5. Send `g` → hand grasps and prints the detected object class
6. Send `r` → re-calibrates the baseline (useful if sensors drift)

### Expected Serial output
```
# Prosthetic Hand — Inference Firmware
# Calibrating baseline...
# Baseline done.
# Ready. Send 'g' to grasp and classify.
# Grasping...
# t1 captured
# t2 captured
RESULT: cylinder_stiff
```

## Feature Vector (56 values)

The same 56 features are extracted identically in both `train_and_export.py`
and `inference.ino`. Do not change the order or calculation in one without
updating the other.

| Index | Description |
|---|---|
| 0–17 | Delta X/Y/Z for all 6 sensors at t1 (first contact) |
| 18–23 | Per-sensor vector magnitude at t1 |
| 24 | Motor encoder angle at t1 (degrees) |
| 25–42 | Delta X/Y/Z for all 6 sensors at t2 (steady grip) |
| 43–48 | Per-sensor vector magnitude at t2 |
| 49 | Motor encoder angle at t2 (degrees) |
| 50–55 | Magnitude change per sensor (t2−t1) — stiffness proxy |

## Troubleshooting

| Problem | Likely cause | Fix |
|---|---|---|
| Motor not found | Wrong baud/ID | Check Dynamixel Wizard, confirm ID=1, baud=57600 |
| t1 never fires | Threshold too high | Lower `CONTACT_THRESHOLD` |
| t2 never fires | Fingers don't fully close | Check `CLOSE_POS_DEG`, increase `GRASP_TIMEOUT_MS` |
| Poor accuracy | Too few samples | Collect more grasps, vary orientation more |
| Poor stiffness discrimination | Objects too similar | Check silicone magnet compression range |
| model.h too large | Too many trees | Reduce `--trees` and `--depth` in training |
